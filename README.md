# Wang's Life Questbook | 100 Challenge

> 「不為除錯，只為體驗。紀錄下半場生命的每一個精彩瞬間。」

一個專為個人人生里程碑打造的單頁 Web 應用程式（Single Page App），以獨立開發者極簡暗黑 Dashboard 風格呈現，幫助你用 100 宮格點亮生命的 6 大探險挑戰。

---

## 🌟 核心特色

### 1. 極簡暗黑科技美學（Dark Mode）
- **主題配色**：極致深邃的背景 `#09090B` 與卡片表面 `#1E293B`，搭配溫暖金黃光暈 (`#F59E0B`) 與高質感翡翠綠 (`#10B981`)。
- **字體設計**：採用現代感 sans-serif 與 JetBrains Mono 等寬編號字型，兼具數位儀表板質感與生活溫度。

### 2. 6 大生命冒險支線（共 600 格）
1. ⚽ **父子 100 場球**：一起流汗、互相傳球，父子間無話不談的綠茵時光。
2. 🍱 **跟爸爸吃 100 次飯**：一碗熱湯、幾句日常，最平凡卻也最珍貴的圍爐對話。
3. 🍻 **100 道下酒菜**：週末夜晚的小酌微醺，親手烹調的極致下酒風味。
4. 💻 **100 個 AI 應用**：探索新科技浪潮，用 AI 動手打造有溫度與解決生活問題的酷專案。
5. 🎨 **100 幅速寫**：隨手拾起畫筆，紀錄眼前光影、街景與那一刻的心境感受。
6. ⛰️ **100 條步道與遠征**：丈量大地的腳步，走向山巔與大海的壯闊冒險（專屬支援：**玉山**、**日本爬山**、**單車環島**、**台灣百岳**、**郊山健行**等標籤篩選）。

### 3. 主體 100 宮格矩陣（100-Grid Matrix）
- **未解鎖狀態（Empty State）**：半透明虛線邊框與沈穩灰字 `#001` ~ `#100`。點擊任意空格可直接指定解鎖該號碼。
- **已解鎖狀態（Unlocked State）**：高亮金色邊框、浮雕微光與高解析縮圖，標註日期與標題。
- **回憶詳情彈窗（Detail Modal）**：點擊已解鎖卡片即可瀏覽完整大圖、解鎖日期、3 句內心得隨筆與專屬標籤，並支援快速編輯或重設。
- **解鎖慶祝儀式**：點擊解鎖時會觸發金色粒子彩帶雨（Canvas Confetti）與卡片呼吸發光動畫，並自動平滑滾動至該卡片！

### 4. 手機端「隨手上傳解鎖」功能 (Quick Upload Modal)
- **右下角懸浮按鈕（FAB Button）**：任何時刻隨手一點，立即記錄當下精彩時刻。
- **智慧自動抓取**：自動推薦當前分類下一個未解鎖的數字（例：`#002`），亦可隨時切換自選。
- **智慧前端圖片壓縮**：內建 HTML5 Canvas 智慧壓縮引擎，手機直接拍照或選取 5MB~10MB 高解析相片時，自動縮放為最適尺寸，將容量壓至約 50KB~80KB，徹底解決瀏覽器 `localStorage` 容量限制！
- **外連網址支援**：亦可點擊「改填圖片網址」，直接貼上線上圖片連結。
- **三句隨筆**：提供 100 字即時字數統計，專注於淬鍊最真切的心境溫度。

### 5. 資料保存與移轉（Data Persistence & Backup）
- **本機永久儲存**：使用瀏覽器 `localStorage`，重新整理或離線皆不遺失。
- **匯出 JSON 備份**：一鍵下載完整 `wang_life_questbook_backup_YYYY-MM-DD.json`。
- **匯入 JSON 備份**：支援智慧合併或復原已備份的回憶資料庫。
- **精選示範資料**：頂部選單提供 ✨ 載入 6 筆精選示範回憶，隨時體驗完整點亮效果。

## 🚀 如何使用

### 本機直接開啟
本應用程式為完全自包含的單一 HTML5 檔案，無需安裝任何伺服器環境或構建工具：
1. 直接用瀏覽器（Chrome、Safari、Edge、Firefox 等）開啟 `Project/100-challenge/index.html`。
2. 或在終端機輸入：
   ```bash
   open "Project/100-challenge/index.html"
   ```

### 部署到線上
你可以將本資料夾或 `index.html` 上傳至任何靜態託管平台：
- **GitHub Pages**：將 `index.html` 放入 GitHub 倉庫並啟用 Pages。
- **Vercel / Netlify / Cloudflare Pages**：將專案資料夾拖曳部署，秒速獲得專屬的個人網址！
- **手機加入主畫面（PWA 體驗）**：在手機 Safari 或 Chrome 中開啟網址，點選「分享」->「加入主畫面」，即可作為全螢幕獨立 App 使用。

## 🛠 技術規格
- **核心架構**：原生 HTML5 + Vanilla JavaScript (ES6+)
- **樣式庫**：Tailwind CSS (Via CDN，具備自定義 Dark Mode、金色/翡翠綠光暈與動畫)
- **圖示庫**：Lucide Icons (Via CDN，帶有安全加載容錯保護)
- **視覺特效**：Canvas Confetti (慶祝彩帶粒子效果)
- **字型**：Inter, JetBrains Mono, Noto Sans TC (Google Fonts)
- **響應式支援**：完美支援 iPhone、Android、iPad 及 Desktop 螢幕尺寸（RWD）
